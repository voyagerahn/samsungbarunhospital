# 삼성바른병원 환자 호출 시스템

환자 태블릿에서 간호사를 호출하면 간호사 태블릿에 알림이 표시되는 시스템입니다.

> 📘 **자세한 설명서**: 처음 설치하시거나 블루투스 보조 통신 설정이 필요하시면 [`docs/manual.pdf`](docs/manual.pdf) (그림과 함께 단계별로 설명된 사용 설명서, 비전문가용)를 참고하세요. 이 README는 이미 사용법을 아는 분을 위한 빠른 참고용입니다.

---

## 설치 전 준비사항

> **필수 조건**: 기본적으로는 환자 태블릿과 간호사 태블릿이 **같은 WiFi**에 연결되어 있어야 합니다.
>
> 📶 **v2.1 신규**: 같은 WiFi가 아니어도 두 태블릿이 물리적으로 가까이 있으면 **블루투스로 보조 전달**됩니다(등록된 IP가 있으면 자동, 한 번도 같은 네트워크였던 적이 없다면 관리자 설정 → 통신 설정 → "근처 기기 검색"으로 직접 등록). 자세한 절차와 한계는 `docs/manual.pdf` 참고.

1. 모든 태블릿에 APK 파일 설치
2. 앱 실행 후 **알림 권한 허용**
3. **블루투스 권한 허용** (물어보면 허용 — 거부해도 앱은 정상 작동하고 WiFi 기능만 사용됨)
4. 배터리 절약 모드에서 앱 **예외 처리** (백그라운드 실행 허용)

## 간호사 태블릿 설정

### 1단계 — 관리자 설정 진입
- 화면 **왼쪽 빈 영역**을 빠르게 **4번 연속 탭**
- 관리자 비밀번호 입력 (기본값: `0819`)
- **앱 관리자 설정** 선택

### 2단계 — 태블릿 이름 설정
- `간호사 스테이션` 등 고유한 이름 입력

### 3단계 — IP 주소 확인
- 설정 화면 상단 **"이 기기의 IP 주소"** 메모
- 예: `192.168.1.105` → 환자 태블릿 설정에 필요

### 4단계 — 저장
- 하단 **저장** 버튼 클릭

> 간호사 태블릿은 **앱이 항상 실행 중**이어야 호출을 받을 수 있습니다.

---

## 환자 태블릿 설정

### 1단계 — 관리자 설정 진입
- 화면 **왼쪽 빈 영역**을 빠르게 **4번 연속 탭**
- 관리자 비밀번호 입력

### 2단계 — 태블릿 이름 설정
- `1호실 1번` 등 병실/병상을 구분하는 이름 입력

### 3단계 — 간호사 태블릿 IP 등록
- **간호사 태블릿 IP 목록** 섹션 → **IP 추가** 버튼
- 간호사 태블릿에서 메모한 IP 입력 (예: `192.168.1.105`)
- 간호사 태블릿이 여러 대면 모두 추가

### 4단계 — 호출 메시지 설정 (선택)
- 호출 시 표시할 메시지 목록 편집
- 예: `너무 아파요`, `주사약이 다 들어갔어요`

### 5단계 — 저장

## 사용 방법

### 환자 태블릿

| 동작 | 기능 |
|------|------|
| 메인 화면 버튼 탭 | 연결된 앱 또는 웹페이지 실행 |
| 🔔 벨 버튼 탭 | 호출 메시지 선택 창 표시 |
| 메시지 선택 후 전송 | 간호사에게 호출 전달 |

### 간호사 태블릿

| 상황 | 동작 |
|------|------|
| 호출 수신 시 | 알림 표시 |
| 알림 탭 | 호출 목록 확인 |
| 처리 완료 | 호출 항목 삭제 |

## 유의사항

| 항목 | 내용 |
|------|------|
| 네트워크 | 환자·간호사 태블릿 모두 같은 WiFi에 연결 필수 |
| 앱 실행 | 간호사 태블릿은 앱이 항상 켜져 있어야 호출 수신 가능 |
| IP 변경 | WiFi 재연결 시 IP가 바뀔 수 있음 → 환자 태블릿에서 IP 재등록 필요 |
| 태블릿 이름 | 각 태블릿마다 서로 다른 이름 설정 권장 |
| 비밀번호 | 관리자 비밀번호 분실 시 앱 재설치 필요 |
| 배터리 | 간호사 태블릿은 항상 충전 상태 유지 권장 |

## 문제 해결

**"전달 실패" 메시지가 뜰 때**
1. 간호사 태블릿에서 앱이 실행 중인지 확인
2. 두 태블릿이 같은 WiFi에 연결되어 있는지 확인
3. 환자 태블릿 관리자 설정에서 간호사 IP가 올바르게 입력되어 있는지 확인
4. WiFi 재연결 후 간호사 IP가 바뀌었을 수 있음 → IP 재확인 후 재등록

**간호사 태블릿에 알림이 안 뜰 때**
1. 태블릿 알림 설정에서 앱 알림 허용 여부 확인
2. 앱 종료 후 다시 실행

**블루투스 보조 통신 관련 문제**
- `docs/manual.pdf`의 "📶 블루투스로 호출이 잘 안 갈 때" / "📶 근처 기기 검색 목록에 아무것도 안 뜰 때" 항목 참고
