## 📋 시스템 개요

환자 태블릿에서 🔔 호출 버튼을 누르면 간호사 태블릿에 알림이 전달되는 시스템입니다. 호출은 두 가지 길로 전달됩니다.

- **📡 Wi-Fi**: 환자 태블릿과 간호사 태블릿이 **같은 Wi-Fi**에 있을 때 — 가장 빠르고 확실합니다
- **📶 블루투스**: 서로 **다른 네트워크**에 있어도, 두 태블릿이 **물리적으로 가까이** 있으면 블루투스로 전달합니다

블루투스 호출은 **Wi-Fi 호출과 똑같이 동작**합니다(통신 수단만 다릅니다). 호출은 항상 **설정에서 등록한 간호사 태블릿**에만 표시되고, 간호사 태블릿이 받으면 환자 화면에 "✓ 간호사에게 전달되었습니다"가 뜹니다. 거리가 멀어 직접 닿지 않으면 근처의 다른 태블릿이 **중계만** 해 줍니다(환자 → 다른 환자 태블릿 → 간호사). 중계하는 태블릿의 화면에는 아무것도 뜨지 않습니다.

간호사 태블릿은 **Wi-Fi와 블루투스 두 길로 동시에** 호출을 받습니다. 같은 Wi-Fi의 환자 태블릿과 다른 네트워크의 환자 태블릿이 섞여 있어도 모두 같은 호출 목록에 표시되며, 같은 호출이 두 길로 와도 알람은 한 번만 울립니다.

> 💬 호출 자체에는 인터넷이 필요 없습니다. 병원 내부 네트워크와 블루투스만으로 작동합니다. (진단 기록을 개발자에게 보낼 때만 인터넷이 필요합니다.)

### 🔗 간호사 태블릿과 멀리 떨어진 환자 태블릿 <span class="new-badge">NEW</span>

환자 태블릿에서는 **간호사 태블릿만 등록하면 됩니다.** 블루투스가 직접 닿지 않는 거리라면, 그 사이에 있는 다른 태블릿을 거쳐 가는 길을 앱이 스스로 찾아 연결합니다(거쳐 가는 태블릿 화면에는 아무것도 뜨지 않습니다). 따로 설정할 것은 없습니다.

- 가까운 태블릿 몇 대는 간호사 태블릿과 직접 연결되고, 나머지는 그 태블릿들을 거쳐 연결됩니다. 그래서 간호사 태블릿의 연결 한도보다 많은 환자 태블릿을 쓸 수 있습니다.
- **태블릿 사이 간격은 10m 안쪽(벽이 있으면 더 가깝게)** 이 좋습니다. 간호사 태블릿에서 가장 먼 태블릿까지, 그 간격으로 태블릿이 이어져 있어야 합니다.
- 중간에서 이어 주던 태블릿이 꺼지거나 옮겨지면, 앱이 다른 길을 찾아 다시 연결합니다(보통 1분 안쪽). 그동안 누른 호출은 10초 안에 연결되면 전달되고, 아니면 "전달 실패"가 뜨므로 다시 누르면 됩니다.
- 지금 어디까지 연결됐는지는 **관리자 설정 → 통신 설정 → 근거리 보조 통신 상태**에서 볼 수 있습니다. **"블루투스로 닿는 태블릿"**에 태블릿 이름과 **직접 연결됨 / 다른 태블릿 N대를 거쳐 연결됨**이 나옵니다. 간호사 태블릿에서 보면 어느 환자 태블릿까지 닿는지 한눈에 알 수 있고, 목록에 없는 태블릿은 닿지 않는 것입니다.
- 환자 태블릿에서 **"간호사 태블릿이 감지되지 않습니다"**가 나오면: 간호사 태블릿과의 사이에 태블릿을 한 대 더 두거나, 태블릿을 간호사 쪽으로 옮긴 뒤 1분쯤 기다려 다시 확인하세요.

## 🚀 설치 전 준비사항

1. ✅ 모든 태블릿에 APK 파일 설치 (기존 버전 위에 그대로 덮어 설치하면 설정이 유지됩니다)
2. ✅ 앱 실행 후 **알림 권한 허용**
3. ✅ **근처 기기(블루투스) 권한 허용** — 거부해도 Wi-Fi 호출은 정상 작동하지만, 블루투스 호출은 사용할 수 없습니다
4. ✅ **블루투스 켜기** — 블루투스로 호출을 주고받는 태블릿은 항상 켜두세요
5. ✅ 배터리 절약 모드에서 앱 **예외 처리** (백그라운드 실행 허용)

## 🩺 간호사 태블릿 설정

### 1️⃣ 관리자 설정 진입
- 화면 **왼쪽 위 빈 영역**을 빠르게 **4번 연속 탭**
- 관리자 비밀번호 입력 (기본값: `0819`)
- **앱 관리자 설정** 선택

### 2️⃣ 태블릿 이름 설정
- **기본 정보** 탭 → 태블릿 이름란에 `간호사 스테이션` 등 고유한 이름 입력
- 이 이름은 환자 태블릿의 **근처 기기 검색 목록**(Wi-Fi·블루투스 모두)에 그대로 표시되므로 알아보기 쉬운 이름으로 정해주세요

### 3️⃣ IP 주소 확인 (같은 Wi-Fi 환자 태블릿이 있을 때)
- **기본 정보** 탭의 **"이 기기의 IP 주소"** 확인 (예: `192.168.1.105`)
- 환자 태블릿에서 "근처 Wi-Fi 기기 검색"을 쓰면 IP를 몰라도 되지만, 직접 입력할 경우를 대비해 메모해두세요

### 4️⃣ 저장
- 하단 **저장** 버튼 클릭

> ⚠️ **주의**: 간호사 태블릿은 **앱이 항상 실행 중**이어야 호출을 받을 수 있습니다. 앱을 완전히 종료하지 마세요. 이름을 바꾼 경우 앱을 한 번 다시 실행해야 Wi-Fi 검색 목록에 새 이름이 반영됩니다.

## 🛌 환자 태블릿 설정

### 1️⃣ 관리자 설정 진입
- 화면 **왼쪽 위 빈 영역**을 빠르게 **4번 연속 탭** → 관리자 비밀번호 입력

### 2️⃣ 태블릿 이름 설정
- `1호실 1번`, `2호실 3번` 등 병실/병상을 구분하는 이름 입력

### 3️⃣ 간호사 태블릿 등록 — 상황에 맞는 방법을 고르세요 <span class="new-badge">NEW v2.2</span>

모두 **통신 설정** 탭에서 합니다.

| 이 환자 태블릿이… | 등록 방법 | 호출 경로 |
|------|------|------|
| 간호사 태블릿과 **같은 Wi-Fi** | **"근처 Wi-Fi 기기 검색"** 또는 **"+ IP 직접 추가"** | 📡 Wi-Fi |
| 간호사 태블릿과 **다른 네트워크** | **"BLE 전용 간호사" 카드 → "근처 BLE 기기 검색"** | 📶 블루투스 |

<div class="callout callout-tip">
💡 <strong>다른 네트워크인 환자 태블릿은 IP가 아니라 "근처 BLE 기기 검색"으로 등록하세요.</strong> IP로 등록하면 호출할 때마다 Wi-Fi 연결을 먼저 시도하고 실패를 확인한 뒤에야 블루투스로 보내므로, 호출이 3~6초 늦게 도착합니다.
</div>

#### 📡 같은 Wi-Fi — 근처 Wi-Fi 기기 검색
1. **간호사 태블릿 IP 목록** 카드 → **"근처 Wi-Fi 기기 검색"** 탭
2. 같은 Wi-Fi에서 앱이 켜져 있는 태블릿 이름과 IP가 나타납니다
3. 간호사 태블릿 이름 옆 **"추가"** → 확인 창에서 이름을 다시 확인하고 **"추가"**

IP를 직접 입력하려면 **"+ IP 직접 추가"**를 누르고 간호사 태블릿에서 메모한 IP를 입력하세요. 간호사 태블릿이 여러 대면 모두 추가합니다.

#### 📶 다른 네트워크 — 근처 BLE 기기 검색
1. 📍 두 태블릿을 **가까이**(1~2m 이내) 두고, 두 태블릿 모두 **블루투스가 켜져 있는지** 확인
2. **BLE 전용 간호사** 카드 → **"근처 BLE 기기 검색"** 탭
3. ⏳ 몇 초 기다리면 근처 태블릿 이름이 나타납니다
4. 간호사 태블릿 이름 옆 **"등록"** → 확인 창에서 이름을 다시 확인하고 **"등록"**

<div class="callout callout-limit">
⚠️ <strong>검색 목록에는 간호사 태블릿뿐 아니라 근처의 다른 환자 태블릿도 함께 나타날 수 있습니다.</strong> 반드시 이름을 확인하고 등록하세요. 다른 환자 태블릿을 잘못 등록하면 호출이 그쪽으로 가서 간호사가 호출을 받지 못합니다.
</div>

### 4️⃣ 등록 상태 확인 <span class="new-badge">NEW v2.2</span>

IP로 등록한 간호사는 목록의 각 줄에 상태가 표시됩니다.

| 표시 / 버튼 | 의미 |
|------|------|
| 마지막 연결 확인: N분 전 | 이 IP와 마지막으로 Wi-Fi 연결에 성공한 시각 |
| 블루투스: 연결됨 / <span style="color:#E65100">연결 안 됨</span> | Wi-Fi가 안 될 때 블루투스로도 호출이 갈 수 있는지. **"연결 안 됨"이면 Wi-Fi가 안 될 때 이 간호사에게는 호출이 가지 않습니다** |
| **테스트** | 지금 이 IP로 Wi-Fi 연결이 되는지 바로 확인 |
| **블루투스 연결** | 간호사 태블릿 옆에서 근처 블루투스 기기를 골라 이 IP에 연결 |
| **삭제** | 목록에서 제거 |

- 같은 Wi-Fi에서 IP를 추가하면 블루투스 연결도 **자동으로** 됩니다.
- 연결할 수 없는 IP를 추가하면 바로 **"블루투스로 연결"**을 권하는 창이 뜹니다.

### 5️⃣ 호출 메시지 설정 (선택)
- **호출 메시지** 탭에서 호출 시 선택할 메시지 목록 편집 (예: `너무 아파요`, `화장실 도움이 필요해요`)
- 💡 간호사 태블릿의 메시지를 그대로 가져오려면 아래 **"간호사 설정 불러오기"**를 사용하세요

### 6️⃣ 저장
- 하단 **저장** 버튼 클릭 (앱 버튼 설정은 저장 버튼과 관계없이 바로 반영됩니다)

## 🛠️ 문제 해결

### "전달 실패" 메시지가 뜰 때
1. 간호사 태블릿에서 앱이 실행 중인지 확인
2. 같은 Wi-Fi라면: 환자 태블릿 **통신 설정**에서 간호사 IP의 **"테스트"** 실행 → 실패하면 IP가 바뀌었을 수 있으니 "근처 Wi-Fi 기기 검색"으로 다시 등록
3. 다른 네트워크라면: 안내 문구 아래 이유를 확인
   - "(블루투스가 꺼져 있습니다)" → 블루투스 켜기
   - "'블루투스 연결'로 등록하세요" → 간호사를 "근처 BLE 기기 검색"으로 등록하거나, IP 줄의 **"블루투스 연결"** 실행

### 📶 "블루투스 연결이 끊겨 있습니다" 안내가 뜨거나, 연결된 기기가 0대일 때
1. **먼저 1~2분 기다려보세요.** 앱이 등록된 간호사 태블릿을 자동으로 계속 다시 찾습니다. 연결이 돌아온 뒤 다시 호출하면 됩니다("전달 실패"가 뜬 호출은 나중에 전달되지 않습니다)
2. 두 태블릿의 블루투스가 켜져 있는지, 너무 멀리 떨어져 있지 않은지 확인
3. 그래도 0대라면 **블루투스를 껐다가 다시 켜세요** — 앱이 자동으로 다시 시작하므로 태블릿을 재부팅할 필요는 없습니다
4. 진단 탭 자가진단에 "주변 기기 검색이 계속 실패"가 나오면 3번을 실행

### 📶 기록에 "찾을 수 있게 하기 실패: 오류코드 12"가 반복될 때 <span class="new-badge">NEW v2.2.4</span>
이 태블릿의 블루투스가 **동시에 연결할 수 있는 수가 가득 찼다**는 뜻입니다(고장이 아닙니다).
1. 통신 설정의 블루투스 상태나 진단 탭 자가진단에 **"이 태블릿은 블루투스로 최대 N대까지 연결됩니다. … 더 추가할 수 없습니다"**라고 표시됩니다 — 그 숫자가 이 태블릿의 한도입니다
2. 이미 연결된 태블릿의 호출은 정상입니다. 새로 붙이려는 태블릿은 이 태블릿에 직접 연결되지 않고, 이미 연결된 다른 태블릿 근처에 있어야 그 태블릿을 거쳐 전달됩니다
3. 간호사 태블릿 한 대에 블루투스로 붙는 환자 태블릿이 한도보다 많다면, 가능한 태블릿은 **같은 Wi-Fi로 연결**하는 것이 가장 확실합니다

### 📶 블루투스로 호출했는데 간호사 쪽 알람이 안 울릴 때
1. 두 태블릿 모두 **진단 탭 → 자가진단 실행** 후 "⚠ 확인 필요" 항목 조치
2. 두 태블릿을 더 가까이 두고 다시 호출
3. 그래도 안 되면 두 태블릿 모두 **"개발자에게 보내기"**

### 📶 "근처 BLE 기기 검색" 목록에 아무것도 안 뜰 때
1. 두 태블릿 모두 블루투스가 켜져 있는지 확인
2. 두 태블릿을 1~2m 이내로 붙이고 몇 초 더 기다리기
3. 두 태블릿이 모두 Android 7이면 서로 찾을 수 없습니다 (📱 지원 기기 참고)
4. 설정 → 앱 권한에서 근처 기기(블루투스·위치) 권한 허용 여부 확인
5. 그래도 안 되면 두 태블릿 모두 앱을 껐다가 다시 실행

### 📡 "근처 Wi-Fi 기기 검색" 목록에 아무것도 안 뜰 때
1. 두 태블릿이 정말 같은 Wi-Fi인지 확인
2. 간호사 태블릿도 **v2.2.0 이상**인지 확인 (이전 버전은 검색 목록에 나타나지 않음)
3. 병원 Wi-Fi 설정에 따라 검색이 막혀 있을 수 있음 → "+ IP 직접 추가" 사용
